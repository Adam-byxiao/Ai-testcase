# 蓝图流程渲染方案（图 + 树 + Figma 融合）

日期：2026-03-23  
状态：草案

## 目标
渲染一个融合视图，包含：
- Figma 解析得到的蓝图节点（可视卡片）
- 流程图（Graph）连线关系
- 流程树（Tree）主流程结构

## 输入
- `flow_graph_*.json`（节点/边列表）
- `flow_tree_*.json`（树结构）
- 蓝图快照（节点 + pins + 布局）

## 渲染策略

### 1) 节点数据源
- 以快照 nodes 作为可视化卡片
- graph 节点负责连线与筛选
- 通过 `node.id` 映射两者

### 2) Graph 图层（连线）
- 按 `flow_graph.json` 渲染连线
- 默认锚点使用节点 header pin
- 如有 pin 映射则优先 pin 级锚点

### 3) Tree 图层（层级）
- `flow_tree.json` 提供主流程展开结构
- Root 为主流程起点
- 多子节点视为分支
- 侧边栏以缩进结构展示树
- 点击树节点可定位/高亮画布节点

### 4) 融合视图
- 主画布显示蓝图 + Graph 连线
- 侧边栏显示流程树
- 树节点点击高亮对应蓝图卡片

## UI 交互
- 模式切换：仅 Graph / 仅 Tree / 混合
- 高亮：Hover 触发节点/连线高亮
- 聚焦：双击树节点，画布居中

## 实施顺序
1. 前端加载 flow_graph / flow_tree
2. 侧栏渲染流程树结构
3. 节点高亮 + 聚焦
4. Graph 连线覆盖
5. 可选：基于树的自动布局

## 输出
- 融合视图：蓝图节点 + 连线 + 树结构
- 支持验证与后续 PRD 生成
